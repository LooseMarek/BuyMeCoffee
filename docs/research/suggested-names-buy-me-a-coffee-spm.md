# Suggested Project Names — Buy Me a Coffee SPM

> Note: This is a private Swift Package (library), not a consumer app — it will not appear on
> the App Store itself. The "App Store" column below checks whether a consumer-facing app
> with the same name already exists, to avoid confusion. GitHub availability is the more
> relevant check for an SPM.

## ✅ Confirmed Name: BuyMeCoffee

Researched on 2026-04-13. No conflicts found:
- The only similar Swift package is `appcraftconsulting/buymeacoffee`, which uses the module
  name **`BuyMeACoffee`** (with "A") — a distinct name. That library is also archived (Jul 2024).
- No other Swift package on GitHub or the Swift Package Registry uses `BuyMeCoffee`.
- No Apple framework uses this name.

**`import BuyMeCoffee`** is clear and available.

> ⚠️ Names to avoid:
> - **TipKit** — Conflicts directly with Apple's own `TipKit` framework (iOS 17+, WWDC23).
> - **BuyMeACoffee** — The archived `appcraftconsulting/buymeacoffee` package uses this module name.
> - **BrewKit** — A beer recipe builder app at brewkitapp.com already uses this name.
